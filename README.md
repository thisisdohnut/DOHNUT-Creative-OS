# DOHNUT Creative OS

**DOHNUT Creative OS** ialah sistem operasi kreatif dan dokumentasi AI untuk DOHNUT, sebuah Malaysian-born premium donut D2C brand di bawah GangNiaga Sdn. Bhd., fokus KL/Selangor (Lembah Klang), online-first dan delivery-led.

## Brand core

> **GOOD VIBE. GOOD DOH.**

DOHNUT menggabungkan premium donut quality, playful tactile creativity, modern Malaysian cultural relevance, distinctive verbal identity, character lore dan AI-assisted production.

## Usage principle

1. Start with **Brand Truth**.
2. Convert the brief into a **Creative Genome**.
3. Select the relevant creative modules.
4. Compile the prompt or content instructions.
5. Generate output.
6. Run quality gates.
7. Record the approved asset, lineage and feedback.

## Important distinction

The Play-Doh reference is treated as **creative inspiration for tactile play**, not as a template to copy. DOHNUT must use original execution, original visual systems and original character/assets.
