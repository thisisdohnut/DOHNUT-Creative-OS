# DOHNUT AI Skills Matrix

## 1. Proficiency scale

| Level | Definition |
| --- | --- |
| **Asas** | Faham konsep dan perlukan supervision |
| **Lanjutan** | Boleh kendali secara bebas dengan rujukan minimum |
| **Ekspert** | Boleh mengajar, mengoptimumkan proses dan menangani edge cases |

## 4. Role archetypes

- **Brand Strategist:** owns brand truth and positioning.
- **Creative Director:** owns concept quality and visual direction.
- **DOH Copy Lead:** owns verbal identity.
- **Character Lead:** owns Doh Boy canon.
- **AI Creative Engineer:** owns compiler, schemas and evaluations.
- **QA/Brand Guardian:** owns quality gates and release readiness.
- **Creative Producer:** owns dependencies, deadlines and deliverables.
