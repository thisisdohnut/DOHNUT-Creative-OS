# DOHNUT IP and Parody Guardrails

## 1. Principle

DOHNUT boleh menggunakan pop-culture references sebagai creative starting points, tetapi execution komersial mesti kekal original dan tidak memberi gambaran bahawa DOHNUT ialah official partner, licensee atau endorser.

## 2. Risk tiers

| Tier | Description | Action |
| --- | --- | --- |
| Low | generic genre inspiration | normal QA |
| Medium | recognisable title/character concept | creative + IP review |
| High | copied logo/art/character/costume/trade dress | block and redesign |

## 3. Do

- Transform the reference.
- Create original typography and composition.
- Create original characters and props.
- Make product and DOHNUT identity dominant.
- Use references as jokes, not source assets.

## 4. Don't

- Copy original poster art.
- Reproduce studio logos.
- Clone characters.
- Copy distinctive costume/pose combinations too closely.
- Suggest official endorsement.
- Use another brand's mark as if it belongs to DOHNUT.

## 5. Escalation

Apabila creative team ragu sama ada sesuatu execution terlalu dekat dengan protected property, asset mesti ditandakan `ip_review_required` dan tidak publish sehingga human review selesai.
